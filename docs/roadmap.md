# Roadmap

These are goals, not commitments or descriptions of current features.

## v0.1.0 — MVP (current)

- [x] Sentiment classification demo (TF-IDF + logistic regression)
- [x] Iris classification with logistic regression and random forest
- [x] Local inference benchmark with JSON/CSV export
- [x] Tests, Ruff linting, and GitHub Actions CI
- [x] Contribution guide, code of conduct, security policy, issue and PR templates

## v0.2.0 — Learning modules

- Regression and clustering (e.g. K-Means) examples
- Cross-validation and evaluation-metric walkthroughs
- Educational Jupyter notebooks in `notebooks/`
- Investigate a computer-vision example, only after reviewing model and dataset licenses

## v1.0.0 — Stable foundation

- Stable, documented public API
- Better evaluation tooling and benchmark variance reporting
- Optional, opt-in integrations with open-source model libraries (e.g. PyTorch, Transformers), kept out of the core dependency set

## Not planned for now

- Hosted services or features that need paid APIs or credentials
- Production deployment tooling
